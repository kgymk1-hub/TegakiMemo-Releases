# Tegaki Memo — Android APK配布

Android向けの手書きメモアプリです。APKと利用説明を公開しています。開発ソースは含みません。

## ダウンロード

[v2.0-beta.1](https://github.com/kgymk1-hub/TegakiMemo-Releases/releases/tag/v2.0-beta.1) の `TegakiMemo-v2.0-beta.1.apk` をダウンロードしてください。
Android 8.0以上。実機検証はOPPO Reno5 A / Android 12、追加検証はAPI37エミュレーターです。
Android 8、実タブレット、物理スタイラス、TalkBack音声での全操作は未確認です。
重要なメモは新しい `.tegaki` 形式で書き出して保管してください。
「Source code (zip/tar.gz)」は配布ページの資料で、インストール用アプリではありません。

## インストール・更新

1. APKを端末にダウンロードして開きます。
2. 必要な場合、ブラウザやFilesに「不明なアプリのインストール」を許可します。
3. インストール後、不要になった許可は戻してください。

正式署名の旧版1.0には上書きインストールできます。自動更新機能はありません。
**改良版はPWA版・旧Android版の.tegakiおよび自動保存データと互換性がありません。**
旧版の内部データは自動移行・削除しませんが、改良版から旧メモを開く機能はありません。
旧メモが必要な場合は更新前に旧版でPNG/.tegakiを書き出して保管してください。
アプリのアンインストールやデータ消去は内部データを削除します。
開発用debug署名アプリとは鍵が異なります。「Tegaki Memo 検証用」は別アプリで、メモを共有しません。

## 主な機能

- ペン、35%マーカー、線全体を消す消しゴム、色・太さ、Undo/Redo
- 図形・文字、範囲選択、コピー・切取り・貼付け、移動・拡縮・90度回転
- 最大5レイヤー、再利用する図の登録・呼出し
- 画像読込、PNG保存、Android専用の新しい.tegaki読込・保存
- メモごとの自動保存、履歴・お気に入り、ピンチズーム、キャンバスサイズ変更
- 全画面・180度表示回転。縦は上下、横は左右の2画面に同じメモを同期表示
- 入力権がある側の青枠・「入力中」表示、各画面の独立ズーム、誤タッチ防止

## 保存と制限

1メモ1ファイルで保存し、操作後約1秒でチェックポイントを作成します。
保存失敗時は編集・ページ移動を止め、再試行できます。復旧ログへの書込前の操作や未確定線は強制終了時に失われ得ます。
文書削除は索引で非表示にし、元ファイルは保持します。完全消去・機密データ抹消機能ではありません。
Undo/Redoは最大100操作・追加保持データ8MiBで、ページ切替・再起動後はリセットされます。
キャンバスは各辺100〜4000、合計800万座標単位。最大2万オブジェクト・50万点。
画像は1枚100万画素/4MiB、最大16枚・合計16MiB。文書展開後32MiBまで。

## 検証とβ版の注意

Debug自動テストは実機・API37で各116件成功。7段階のプロセス強制終了からの復旧も両環境で成功しました。
配布署名APKはOPPOで旧正式版への上書き、起動、描画、PNG保存、再起動後の復元と上下2画面を確認しました。新規インストールは未検証です。
実際の容量不足・物理電源断・数時間の連続運転は未検証です。
初期化処理は軽くしましたが、30回比較で起動全体の高速化は確認できていません。
